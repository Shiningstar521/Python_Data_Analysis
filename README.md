# Online Retail II 电商销售数据分析与可视化

## 项目简介

本项目基于 `data/raw/online_retail_II.xlsx` 中的 Online Retail II 零售交易数据，使用 Python 完成数据探索、清洗、销售分析与可视化，最终形成可复用的分析流程、图表和报告。

当前仓库已建立项目目录骨架。数据文件为 Excel 工作簿；本机当前没有可用的 Python 环境，因此尚未直接读取工作簿核实其工作表、实际字段及行数。Online Retail II 常见版本包含两个期间工作表（2009–2010、2010–2011）及以下字段，开始分析时请以本地文件实际内容为准：

| 常见字段 | 含义 | 可用于 |
| --- | --- | --- |
| `Invoice` | 发票/订单编号 | 订单统计；取消订单识别 |
| `StockCode` | 商品编码 | 商品维度汇总 |
| `Description` | 商品描述 | 商品展示、缺失信息检查 |
| `Quantity` | 商品数量 | 销量及退货/异常检查 |
| `InvoiceDate` | 发票日期时间 | 时间趋势 |
| `Price` | 商品单价 | 销售金额计算 |
| `Customer ID` | 客户编号 | 客户数及客户行为（如字段完整度允许） |
| `Country` | 国家/地区 | 地区销售对比 |

数据集中没有现成的商品类别字段。除非另行引入可信的商品分类映射，不应把商品描述推断出的类别当作原始事实。销售金额的具体口径（如数量 × 单价、取消订单和退货如何处理）应在报告中明确说明。

## 项目目标

- 检查工作簿结构、字段类型、缺失值、重复记录及异常交易。
- 明确订单、销售额、销量等核心指标的计算口径。
- 分析销售额、订单数和销量的时间变化。
- 比较商品及国家/地区的销售表现。
- 将清洗结果、图表和结论保存到约定目录，便于复现和查阅。

## 建议指标与分析方向

- **销售金额**：根据确认后的业务口径，由 `Quantity` 与 `Price` 计算。
- **订单数**：按有效发票编号去重统计；先确认取消发票的编码规则。
- **销量**：按清洗规则汇总 `Quantity`，对退货/负数数量单独处理或展示。
- **商品表现**：按 `StockCode` 汇总销售金额、销量和订单覆盖数。
- **地区表现**：按 `Country` 汇总销售金额、订单数及销量。
- **时间趋势**：按月（必要时按日）观察销售指标，并注意两个工作表覆盖的期间。
- **客户分析（可选）**：在 `Customer ID` 缺失情况允许时分析客户数和购买行为；避免将缺少客户编号的交易误当作单一客户。
